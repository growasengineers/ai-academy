# C01-L01 companion code: linear regression and gradient descent from scratch

This is the code behind the video "How Machines Learn from Examples". Everything runs on a laptop CPU in about a
second. There is no network access, no API key and no GPU.

## Setup

```bash
cd C01-L01-how-models-learn/code          # this folder, wherever you cloned it
python3 -m venv .venv && source .venv/bin/activate      # optional but recommended
pip install -r requirements.txt
```

Verified on 2026-10-25 with:

| | version |
|---|---|
| Python | 3.13.17 |
| numpy | 2.5.3 |
| scikit-learn | 1.9.1 (used only to cross-check our answer) |
| scipy | 1.18.1 (installed with scikit-learn) |
| pytest | 9.1.1 |

Hardware: any CPU. Peak memory is a few megabytes.

## Run

```bash
python3 walkthrough.py          # the whole lesson in order: data, by-hand example, learning rates, scaling, checks
python3 facts.py                # every number the video says or shows, computed by this code
python3 solutions_c01_l01.py    # reference solutions for the coding exercises (do the exercises first!)
```

Run the tests from this folder:

```bash
python3 -m pytest -q
```

## Experiment record (SPEC §11.2)

- **Dataset and source:** synthetic, generated by `data.make_study_data` (no real people, no licence questions).
- **Split:** a seeded shuffle (`SPLIT_SEED = 14`) gives 30 training and 10 test rows with no overlap (tested). The
  test rows are never used for fitting or for choosing hyperparameters.
- **Preprocessing:** none for the raw run. For the scaled run, z-score standardisation of hours using the
  **training** mean and standard deviation only.
- **Model:** ŷ = w·x + b. Loss: MSE. Optimiser: full-batch gradient descent from w = b = 0.
- **Training settings:** raw hours, η = 0.01 for 1000 steps (narrated run); a rate sweep over
  0.001–0.025 for 1000 steps; standardised hours, η = 0.1 for 100 steps.
- **Baselines and references:** closed-form least squares (`numpy.linalg.lstsq`), scikit-learn `LinearRegression`,
  and a deliberately bad memoriser (nearest training student).
- **Results** (all printed by `facts.py`): least squares w ≈ 4.83, b ≈ 40.54; training MSE 15.76; test MSE 18.75;
  memoriser training MSE 0, test MSE 35.31; across 200 fresh synthetic datasets the memoriser lost 179 times.
- **Limitations:** a tiny, one-feature synthetic dataset with Gaussian noise and a truly linear rule. Real data is
  rarely this kind. The 10-row test set is small, so its MSE is noisy (that is why the 200-dataset repeat exists).
  Convergence means "within 0.1 % of the least-squares training MSE", a teaching criterion, not a library default.

## Not a production implementation

This code is educational: it shows every step. In real projects use
`make_pipeline(StandardScaler(), LinearRegression())` from scikit-learn, or `SGDRegressor` for very large data.
